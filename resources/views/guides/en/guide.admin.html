Admin guide

Admins configure a project and run its lottery. Their tools are in the Administration group of the menu: Setup lists, in order, what is left to set up. Every ? explains its page, and offers a guided tour.

Starting a project

Anyone with an account can start a project, and becomes its first admin. New projects work within some limits (people, families and units, invitations a day, file storage) until a superadmin approves them: ask for approval from Setup once you are ready.

Setting it up

  1. Unit types: groups of equivalent units, like "2 bedrooms". Each type is its own lottery.
  2. Units: each with its type. Add and continue loads many quickly; a new type can be created on the way.
  3. Families: each with its type. There should be as many units as families of each type.
  4. Invitations: invite people into their family (or as fellow admins). Families can then invite their own people.
  5. Plan: place the units and draw what surrounds them, on as many floors as needed.

People and roles

In People you move someone to another family, make them an admin, or remove them from the project. An admin may also belong to a family. A project always keeps at least one admin.

Events

Drafts are visible to admins only, until published. An event can ask people whether they will go; you see who goes.

The lottery

Set its date in Lottery: families can change their rankings until then. Once the date arrives, check that each type has as many units as families, and run it. If the numbers differ you are asked to confirm, and some families or units are left over. The result is final and recorded step by step.

Only in exceptional cases (a family registered with the wrong type, a missing family…), invalidate the run: every assignment is cleared, and everyone in the project reads who did it and why. The lottery can then run again; the earlier run stays on record.

Deleting the project

In Settings, by typing its name. A project with a history (other people, events, files, a lottery) is archived for the platform's records: it is gone for everyone, and only a superadmin can bring it back.
